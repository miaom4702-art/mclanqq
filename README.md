# MC 联机 QQ（mclanqq）

### Minecraft Forge 1.20.1 · QQ 风格联机聊天模组

![icon](docs/icon.png)

> 一个面向 **Minecraft Forge 1.20.1** 的“QQ 风格”联机聊天模组。
> **客户端可选**：没安装的玩家照样能进入装了本模组的房间，只是看不到聊天界面。

---

## 1. 这个项目解决什么问题

原版 Minecraft 的聊天把系统提示、死亡信息、进度、玩家发言全混在一起，队内私聊不方便，新消息也容易被忽略。联机时想“像 QQ 一样”单独找某个玩家聊天、并且不错过消息，原版做不到。

本模组在游戏内提供一个独立的聊天窗口，把**大厅群聊**与**玩家私聊**分开，并在收到新消息时用**提示音 + 弹窗 + 未读角标**显著提醒。所有通信都通过 Minecraft 自身的网络通道由服务器转发，**不依赖 QQ 账号、不需要任何外部服务或服务器**。

## 2. 主要功能

- **大厅群聊**：同房间所有在线玩家一个频道
- **玩家私聊**：点击左侧在线玩家即可单独聊天
- **新消息提醒**：提示音 + 右上角弹窗 + 底部“按 [0] 打开…”未读提示 + 每个会话的未读角标
- **看完自动已读**：打开对应会话即清除该会话的未读与弹窗（弹窗本身 6.5 秒后也会自动淡出）
- **每人专属配色**：名字与消息气泡按昵称生成不同颜色，头像使用同一色系，便于区分发言人
- **二次元像素风界面**：樱花夜色平铺背景、粉紫圆角面板、按昵称生成的 Q 版猫娘头像（猫耳/大眼/腮红）
- **客户端可选**：模组声明 `displayTest=IGNORE_ALL_VERSION`，通道接受缺失版本，未安装的玩家可正常联机（不影响原版）
- **单人自测指令**：`/mcqq test`、`/mcqq testdm`
- 默认按键 **数字 0**，可在“按键设置”中修改

## 3. 安装方法

**环境要求**

- Minecraft **1.20.1**
- **Forge 47.x**（开发与测试使用 47.4.22）
- **Java 17**

**普通安装**

1. 到本仓库的 **Releases** 下载 `mclanqq-0.1.0.jar`
2. 把它放进 `.minecraft/mods/` 文件夹
3. 用 Forge 1.20.1 启动游戏

**多人联机**

- 想要使用聊天功能的所有玩家（含房主/服务端）都需要安装同一个 jar
- 未安装 mod 的玩家**依然可以进入房间**，只是看不到本模组的聊天界面，不影响原版联机

**从源码构建**

```bash
./gradlew build
# 产物：build/libs/mclanqq-0.1.0.jar
```

## 4. 使用方法

1. 进入游戏后按 **0** 打开“联机 QQ”窗口
   - 改键：`选项 → 控制 → 按键绑定 → 分类「MC 联机 QQ」`
2. 左侧列表：
   - 「**联机大厅**」= 所有在线玩家群聊
   - 点击某个玩家 = 与他私聊
3. 底部输入框输入内容，`Enter` 发送，`Shift+Enter` 换行
4. 收到别人消息时：播放提示音，右上角出现弹窗，底部出现未读提示；打开对应会话后自动标记已读
5. 单人也能测试：聊天栏输入 `/mcqq test`（模拟收到大厅消息）或 `/mcqq testdm`（模拟私聊）

**和朋友联机**

- 同一局域网：房主在游戏内 `Esc → 对局域网开放`，朋友用 `房主IP:端口` 进入
- 异地联机：借助 ZeroTier / Tailscale / 端口映射等，让朋友连到房主

## 5. 输入输出示例

**例 1 · 大厅发消息**

- 输入：在「联机大厅」输入 `大家好，我是小明` 并回车
- 输出：所有安装了本模组的玩家看到消息 `小明: 大家好，我是小明`（按昵称着色的气泡与头像），并收到提示音、右上角弹窗和未读角标；正在看大厅的人不会弹窗

**例 2 · 私聊**

- 输入：点击左侧玩家 `阿狸`，输入 `在吗？` 并回车
- 输出：只有你和 `阿狸` 的客户端显示这条消息；`阿狸` 会收到提示音与弹窗

**例 3 · 网络包结构（开发者参考）**

发送（客户端 → 服务端），`ChatSendPacket`：

```
scope = "group"             // 群聊
scope = "<目标玩家UUID>"     // 私聊
text  = "消息内容"
```

广播（服务端 → 客户端），`ChatBroadcastPacket`：

```
scope      = "group" | "dm"
fromUuid   = "发送者UUID"
fromName   = "发送者名称（玩家登录名）"
targetUuid = "私聊对象UUID（群聊为空）"
text       = "消息内容"
time       = 毫秒时间戳
```

**例 4 · 测试指令**

- 输入：`/mcqq test`
- 输出：提示 `已模拟收到一条消息，注意右上角弹窗和提示音`，同时播放提示音并弹出通知卡片

## 项目结构

```

  McLanQqMod.java               主类（注册网络通道）
  network/                      ChatSendPacket / ChatBroadcastPacket / NetworkHandler
  client/                       GUI、通知、头像、按键、客户端指令
src/main/resources/
  META-INF/mods.toml            模组声明
  assets/mclanqq/textures/gui/  像素贴图
  assets/mclanqq/lang/          中英文语言文件
tools/gen_textures.ps1          像素贴图生成脚本（开发用）
```

## 说明与限制

- 消息中显示的发送者名称 = 玩家在该服务器上的**登录名**，暂不支持自定义昵称
- 模组只使用自定义网络包通信，不改动原版聊天与游戏逻辑
- 需要通信的双方（房主与玩家）都安装本模组；仅一方安装时，未安装方无法使用聊天功能，但可正常游戏
